### Selected projects & products

- **[IBE Barcode Generator](https://github.com/bobhuang1/IBEBarcodeGenerator)** — free, open-source, cross-platform barcode label generator: 16 legacy formats plus QR, Data Matrix, PDF417 and Aztec, an Avalonia desktop app and a Blazor web app, and PDF label sheets. (MIT) → [try it at generator.ibebarcode.com](https://generator.ibebarcode.com)
- **[IBE Barcode Scanner](https://github.com/bobhuang1/IBEBarcodeScanner)** — iOS and Android barcode/NFC scanner in .NET MAUI that reads what the generator prints, including MSI Plessey and USPS Postnet that mainstream scanning SDKs don't support. (MIT)
- **[AI-Enabled RMA](https://github.com/bobhuang1/AIEnabledRMA)** — AI-assisted returns-and-repairs wizard with deterministic eligibility policy, per-product paid-repair pricing, and MCP policy tools.
- **[DotNetCode](https://github.com/bobhuang1/DotNetCode)** — reusable .NET building blocks: resilient SQL access, input validation, identity helpers, diagnostics, and Microsoft Graph email.
- **[AccessToBlazer](https://github.com/bobhuang1/AccessToBlazer)** — converting a classic Microsoft Access database to an ASP.NET Core Blazor app on .NET 10 with EF Core.
- **Embedded & IoT** — a family of ESP8266/ESP32 builds: [Geiger counter](https://github.com/bobhuang1/ESP12-GeigerCounter-SPI-New12864), [weather station](https://github.com/bobhuang1/ESP12-WeatherStation-I2C-12864-WeatherApi-zh), [RSS reader](https://github.com/bobhuang1/ESP12-RSSReader), [GPS clock](https://github.com/bobhuang1/NANO-GPSClock-I2C-2XTM1637), [piano humidity control](https://github.com/bobhuang1/ESP12-PianoHumidityControl-SPI-Mini12864-zh), and [OpenSCAD models](https://github.com/bobhuang1/OpenSCADModles).
- **[ZhouGongDreamDictionary](https://github.com/bobhuang1/ZhouGongDreamDictionary)** — a classical Chinese dream book (周公解夢) in plain language, with localized retrieval and Gemini-assisted readings.
